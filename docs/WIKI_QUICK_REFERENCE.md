# Wiki 知识中心 - 快速参考指南

**简单易用的 Wiki 知识库操作指南**

---

## 🚀 5 分钟快速开始

### 第一步：新建词条
```
点击 [新建词条]
  ↓
输入标题、分类、标签
  ↓
编写 Markdown 内容
  ↓
点击 [保存] 保存为草稿
```

### 第二步：发布版本
```
编辑完成后，点 [发布版本]
  ↓
输入发布说明（如 "新增响应式设计部分"）
  ↓
点 [发布] 确认
```

### 第三步：搜索和阅读
```
在搜索框输入关键词
  ↓
从列表选择词条
  ↓
使用阅读工具条进行页内检索
```

## 💡 常用操作

### 搜索和过滤

| 操作 | 步骤 |
|------|------|
| **全文搜索** | 在搜索框输入关键词，支持标题、摘要、标签、正文 |
| **分类过滤** | 选择"分类"下拉，选择或新增分类 |
| **排序** | 选择"排序"下拉：最近更新/浏览最多/标题 A-Z |
| **仅显示收藏** | 勾选"仅收藏"复选框 |

### 阅读功能

| 功能 | 操作 |
|------|------|
| **页内检索** | 在"阅读工具条"输入关键词，自动高亮 |
| **快速导航** | 点"上一个"/"下一个"在搜索结果间跳转 |
| **页首/页尾** | 快速返回或跳到文章末尾 |
| **定位词条** | 点"定位词条"，列表自动滚动到当前项 |

### 版本管理

| 操作 | 步骤 |
|------|------|
| **查看历史** | 打开词条 → 点"历史"标签 |
| **恢复版本** | 历史列表 → 点"恢复"按钮 |
| **比对版本** | 点"查看"按钮查看该版本内容 |

### 数据操作

| 操作 | 文件格式 | 用途 |
|------|--------|------|
| **导出 JSON** | `.json` | 完整备份（含历史、注解） |
| **导出 CSV** | `.csv` | 简表格式（标题、分类、摘要） |
| **导入文档** | `.md/.txt/.pdf` | 从文档快速创建词条 |
| **导入 JSON** | `.json` | 恢复备份数据 |
| **导入 CSV** | `.csv` | 批量导入表格数据 |

## 🐛 常见问题

### Q: 如何添加段落注解？
**A:** 在阅读视图中，选中文本 → 右键 → 选择"添加注解" → 输入内容

### Q: 能否在手机上使用？
**A:** 可以！Wiki 完全响应式设计，手机端自动调整布局

### Q: 导入失败了，如何排查？
**A:** 查看"导入日志"面板，显示每个导入操作的结果和错误信息

### Q: 如何快速找到收藏的词条？
**A:** 勾选"仅收藏"复选框，只显示已收藏的词条

### Q: 搜索不到某些词条怎么办？
**A:** 检查是否有以下过滤生效：
- 分类过滤（检查分类下拉是否为"全部分类"）
- 仅收藏（勾选时只显示收藏词条）
- 排序可能导致显示位置改变（往下滚查看）

### Q: 如何恢复误删的词条？
**A:**
1. 刷新页面前，尽快操作（如果有撤销历史）
2. 从导出的 JSON 备份恢复
3. 查看版本历史，可能有该词条的历史版本记录

### Q: 支持多少个词条？
**A:** 理论上无限制，但建议：
- < 1000 个：性能最佳
- 1000-10000 个：虚拟滚动优化，仍需几秒加载
- > 10000 个：考虑使用全文索引搜索引擎（后续版本）

## 📱 响应式设计

### 桌面端 (1920px+)
- 左侧列表（固定宽度 300px）
- 右侧内容区（自适应）
- 阅读工具条为单行网格

### 平板端 (768px-1920px)
- 列表可缩小
- 内容区自适应
- 阅读工具条 2 列网格

### 手机端 (< 768px)
- 列表和内容切换显示
- 打开词条时，列表自动隐藏
- 点"返回列表"回到列表视图
- 阅读工具条自动折叠为紧凑模式

## 💾 数据存储和备份

### 数据存储位置
```
浏览器本地存储：
  localStorage['wiki_articles']  ← 所有词条数据

服务器备份：
  /server/server/data/wiki/library.json  ← JSON 备份
```

### 备份策略

| 方式 | 频率 | 优点 |
|------|------|------|
| **自动本地保存** | 实时 | 编辑时自动保存，不丢数据 |
| **导出 JSON** | 手动 | 完整备份，可恢复到其他设备 |
| **导出 CSV** | 手动 | 适合 Excel 等工具处理 |
| **服务器同步** | 手动触发 | 长期备份，防止本地设备故障 |

### 导出建议
- **日常**：编辑重要词条后，立即导出 JSON
- **周期**：每周导出一次完整备份
- **共享**：导出 CSV 分享给团队成员
