# 企业级流程图编辑提升提案

## 1. 目标
- 目前的编辑器聚焦基本步骤 CRUD 和自动保存，制作流程资产和协作分享仍然欠缺；
- 本文档在描述 | 设计 | 实现路径上补齐差距，目标是将流程图编辑升级为“大型组织的可治理流程平台”。

## 2. 与主流企业平台的功能对比
| 能力 | 现状 | 大厂典型行为 | 优先级 |
| --- | --- | --- | --- |
| 版本与发布 | 仅有单一流程实时编辑 | Camunda、ServiceNow 具备草稿/发布/归档版本管理，并可回滚 | ① |
| 审批与协作 | 仅步骤备注和条件开关 | 支持评论/审批节点、@角色提醒、任务指派 | ② |
| 条件分支与泳道 | 列表 + 简单预览 | 使用条件泳道视图、动态分支连线（执行路径高亮） | ③ |
| 导出与审计 | 新增预览/下载页（JSON/Markdown + 弹窗） | 自动生成 PDF/Word/JSON，并保留导出记录 | ② |
| 权限粒度 | 角色控制页面访问 | 支持操作级权限（谁可以发布、下载、注释） | ③ |
| 数据追踪 | 无执行/审批数据 | 具备执行日志、指标、审批状态历史 | ④ |

## 3. 云端协作/治理需求
1. **版本快照**：用户在保存时可创建版本（草稿、待发布、已发布）；列表可展示版本号、发布时间、发布人、摘要，支持回滚。
2. **审批/协作评论**：每个步骤/流程支持评论区，附带上下文（谁、何时、内容）、状态标签（待处理/已解决）、可 @ 用户提醒。
3. **条件泳道**：画布支持泳道布局与条件线，高亮当前选择的路径，并允许从列表快速插入 “条件分支” 跨越多个步骤。
4. **导出+审计控制**：支持 JSON/Markdown/PDF/Word 输出，并记录导出事件（谁、格式、时间、附带版本）。
5. **权限与审计**：为发布/下载、评论、编辑等动作定义权限组，所有操作写入审计日志表格。

## 4. 架构概览
### 4.1 前端
- `FlowDiagramEditor`：新增版本侧栏，支持版本切换/创建、条件画布视图、评论面板。
- `FlowPreviewExport`：作为预览与导出中心，展示元数据、步骤、操作日志。
- `FlowVersionHistory`（未来）：集中显示版本、发布记录。

### 4.2 后端
- `/flows/:id/versions`：GET/POST/DELETE，记录版本 payload、作者、状态。
- `/flows/:id/comments`：CRUD 评论，带 `stepId`、`status`、`mentionedUsers`。
- `/flows/:id/export`：支持 query `format=json|markdown|pdf|word`，返回文件流/URL。
- `/flows/:id/audit`：GET 审计日志（操作/角色/结果）。
- `/flows/:id/execution-metrics`：可选，记录执行次数、失败率等。

### 4.3 数据模型
```json
{
  "flowVersion": {
    "id": "flow_v_123",
    "flowId": "flow_abc",
    "name": "归档版本 2",
    "status": "published",
    "stepsSnapshot": [...],
    "createdBy": "user_id",
    "createdAt": "2026-02-26T12:00",
    "note": "审批新增条件"
  },
  "auditEntry": {
    "flowId": "...",
    "action": "export",
    "format": "pdf",
    "performedBy": "...",
    "timestamp": "...",
    "metadata": { "version": "flow_v_123" }
  }
}
```

## 5. UX草图说明
- 顶部：面包屑 + 操作按钮（新版本、发布、导出、审批模拟），右上角显示当前角色与审计链接；
- 左侧：流程/版本列表（可展开历史、搜索、按状态筛选），每个流程携带“打开”“回滚”按钮；
- 中央：画布区左侧可切换条件/泳道视图（类似 Swimlane + 条件线），右侧是属性/角色面板；
- 右侧：步骤详情 + 协作评论区（持续滚动）。
- 底部：执行指标摘要 + 审计时间轴（查看/导出等操作）。
- 移动预览：现有 `FlowPreviewExport` 页面即为手机/嵌入预览的入口。

## 6. 实现计划
1. **阶段 1：版本 + 审计**
   - 前端：`FlowDiagramEditor` 加入版本侧栏、状态 badge、发布按钮。
   - 后端：版本 API + 审计日志存储、`FlowPreviewExport` 展示日志。
2. **阶段 2：条件泳道与协作**
   - 画布可渲染泳道、条件线；步骤可带 `tip`/`note`（已实现）。
   - 评论面板、角色指派与条件审批。
3. **阶段 3：导出与分享**
   - `FlowPreviewExport` 提供下载（JSON/Markdown + 将来 PDF）、新窗口预览（已实现）。
   - 建立导出审计记录。
4. **阶段 4：指标与移动/嵌入**
   - 显示执行数据；提供嵌入/分享链接（iframe、外部查看）。

## 7. 验收标准
- 每个流程至少支持一个“版本”，并可回滚；
- `FlowPreviewExport` 能导出 JSON 与 Markdown，未来扩展 PDF/Word；
- 导出/预览操作均写入审计消息；
- 所有主要 UI 触点在移动端可访问，已有的响应式设计应保持；
- 条件步骤/提示能在预览中完整体现（参考当前 `FlowDiagramEditor` 与 `FlowPreviewExport`）。
