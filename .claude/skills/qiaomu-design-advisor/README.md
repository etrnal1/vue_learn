# 乔木设计顾问 Skill

这是一个集成到你的 Claude Code 项目中的设计咨询 skill。

## 🚀 快速开始

当你需要设计帮助时，使用以下触发词：

- "重新设计 [页面]"
- "优化 [功面的 UI"
- "UI 审查"
- "设计建议"
- "这个设计有问题"

## 📖 完整说明

详见 `SKILL.md` 文件，包含：
- 核心设计理念
- 三阶段工作流（诊断 → 方案 → 执行）
- 设计原则和清单
- 使用示例

## 🎯 关键特点

✨ **深度诊断** - 不相信用户的第一句话，像侦探一样调查真实需求

🎨 **三个方案** - 渐进优化、结构重设计、理想愿景，都有清晰的权衡

🔍 **像素级完美** - 覆盖所有状态（Empty, Loading, Error, Success）

💪 **不妥协的标准** - 基于乔布斯和迪特·拉姆斯的设计哲学

## 📝 使用示例

```
用户: 重新设计登录页面，用户经常放弃注册

设计顾问会：
1. 诊断真实问题（用户在哪里放弃？为什么？）
2. 提出三个方案（最小改动 vs 结构重设计 vs 理想方案）
3. 执行细节方案（像素级完善，覆盖所有交互状态）
```
