# Knowledge Base PWA

独立工作区版本的本地知识库 PWA。

## 开发

```bash
cd /Users/mac/vue-learning-app/knowledge-base-pwa
npm install
npm run dev
```

开发地址默认是 [http://localhost:5180](http://localhost:5180)。

## 构建

```bash
npm run build
npm run preview
```

## 功能

- 导入 `.docx` / `.xlsx`
- IndexedDB 持久化
- 文档列表管理
- 全文搜索
- Word / Excel 阅读
- `manifest` + `service worker` 离线壳
